# 살아남을지도 (Survivo)

> 서울 창업 예정지 하나만 입력하면, 30초 안에 상권 생존 가능성을 확인할 수 있는 공공데이터 시각화 도구

---

## 프로젝트 소개

소상공인 창업자는 입지를 결정하기 전 유동인구, 동종업종 밀집도, 임대료를 각각 다른 출처에서 직접 수집해야 한다. 공공데이터포털에 관련 데이터가 공개되어 있지만 CSV 파일을 내려받아 해석해야 하는 구조여서, 비개발자에게는 사실상 접근이 어렵다.

**살아남을지도**는 흩어진 3종의 공공데이터를 하나의 지도 화면으로 통합해, 주소 입력만으로 상권 리스크를 즉시 파악할 수 있게 한다.

### 핵심 기능

- **주소 검색** — 서울 내 주소 또는 지역명 입력 시 지도 이동 및 반경 500m 분석 영역 표시
- **동종업종 밀집도** — 업종 선택 후 반경 내 동종업체 수·위치를 지도 마커로 시각화
- **생활인구 차트** — 선택 행정동의 시간대별·요일별 생활인구를 막대 차트로 표시
- **임대 지표** — 권역·상가 유형 기준 ㎡당 임대료, 공실률, 임대가격지수 추이 표시
- **생존 가능성 스코어** — 3개 지표를 가중 합산한 0~100점 스코어와 A~D 등급 산출

## 실행 방법

### 사전 준비

1. [카카오 디벨로퍼스](https://developers.kakao.com)에서 앱을 생성하고 JavaScript 키를 발급받는다
2. 앱 설정 > 카카오맵 > 사용 설정을 ON으로 변경한다
3. 플랫폼 설정에서 `http://localhost:5173` 도메인을 등록한다

### 환경 변수 설정

`.env.example`을 복사해 `.env` 파일을 생성하고 발급받은 키를 입력한다.

```bash
cp .env.example .env
```

```
# .env
VITE_KAKAO_MAP_KEY=발급받은_JavaScript_앱_키
```

### 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build

# 빌드 결과 미리보기
npm run preview
```

## 생존 스코어 산출 방식

상권 밀집도·생활인구·임대가 3개 지표를 균등 가중치(각 33%)로 합산한 0~100점 지수.

| 등급 | 점수 | 의미 |
|---|---|---|
| A | 80점 이상 | 생존 가능성 높음 |
| B | 60점 이상 | 양호 |
| C | 40점 이상 | 주의 필요 |
| D | 40점 미만 | 리스크 높음 |

> 밀집도는 업종 특성에 따라 방향성이 다르게 적용된다. 경쟁형 업종(카페·편의점 등)은 밀집도가 높을수록 불리하게, 집객형 업종(학원·병원 등)은 유리하게 계산된다.

## 프로젝트 범위

**포함**
- 서울 전 행정동 상권 분석
- 공공데이터 기반 정보 제공 (비실시간)
- 로컬스토리지 기반 로그인·최근 검색 저장

**미포함**
- 서울 외 지역 (데이터 미제공)
- 실시간 데이터 갱신
- 매출·수익 예측
- 모바일 네이티브 앱

## 폴더 구조

```
survivo/
├── public/
│   └── data/
│       ├── storeData/        # 구별 상가정보 JSON (25개 파일)
│       ├── peopleData/       # 생활인구 + 행정동코드 매핑
│       └── priceData/        # 임대동향 (공실률·임대료)
├── src/
│   ├── components/           # UI 컴포넌트 (Map / Panel / Search / Filter / Auth / common)
│   ├── pages/                # 페이지 컴포넌트 (Home / Login / SignUp / NotFound)
│   ├── store/                # Zustand 전역 상태
│   ├── types/                # TypeScript 인터페이스
│   ├── utils/                # 유틸리티 함수
│   ├── hooks/                # 커스텀 훅
│   └── scripts/              # 공공데이터 전처리 스크립트
├── e2e/                      # Playwright E2E 테스트
└── docs/                     # 프로젝트 문서
```
